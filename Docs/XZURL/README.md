# XZURL

## Example

To run the example project, clone the repo, and run `pod install` from the Pods directory first.

## Installation

XZURL is available through [CocoaPods](https://cocoapods.org). To install it, simply add the following line to your Podfile:

```ruby
pod 'XZURL'
```
