## 环境需求 Requirements

iOS 13.0, Swift 6.0, Xcode 16.0.

## 安装集成 Installation

- 使用 [CocoaPods](http://cocoapods.org) 集成

```ruby
pod "XZKit"
```

## 如何使用

```objc
XZLog(@"This is an %@", @"apple");
```
